# Paradise Nursery - Aplicacion de Carrito de Compras

## Descripcion del Proyecto

**Paradise Nursery** es una aplicacion web de carrito de compras para una tienda de plantas en linea. La aplicacion permite a los usuarios explorar diferentes categorias de plantas de interior, ver detalles como imagenes, nombres, descripciones y precios, agregar plantas a un carrito de compras y gestionar los articulos del carrito.

## Caracteristicas

- Pagina de inicio con imagen de fondo y boton de "Comenzar"
- Navegacion entre las secciones de Inicio, Plantas, Nosotros y Carrito
- Visualizacion de plantas organizadas por categorias
- Boton "Agregar al Carrito" que se desactiva al agregar el producto
- Icono de carrito con conteo dinamico de articulos
- Gestion completa del carrito (agregar, eliminar, aumentar/disminuir cantidad)
- Calculo de subtotales por producto y total general
- Pagina "Sobre Nosotros" con informacion de la empresa

## Tecnologias Utilizadas

- React 18
- Redux Toolkit (gestion de estado)
- React Router DOM v6 (enrutamiento)
- Vite (herramienta de construccion)

## Categorias de Plantas

1. **Plantas de Interior con Flores** - 8 plantas
2. **Plantas de Follaje** - 8 plantas
3. **Suculentas y Cactus** - 8 plantas

## Instalacion y Uso

```bash
npm install
npm run dev
```
